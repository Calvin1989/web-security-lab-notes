# 工具扫描结果说明

本目录用于保存本地授权靶场中的工具辅助测试结果。

## 目录说明

- `nmap`：本地服务识别结果；
- `dirscan`：目录枚举结果；
- `sqlmap`：SQL 注入辅助验证结果；
- `nuclei`：自动化模板扫描结果。

## 使用边界

所有扫描均在本地 DVWA、Pikachu 授权靶场中完成，仅用于学习、报告编写和工具辅助验证练习。

工具结果只作为线索，不直接等同于漏洞结论。最终判断需要结合 Burp 抓包、页面响应、业务逻辑和人工复核。

## 工具定位

| 工具 | 作用 | 项目中的用途 |
|---|---|---|
| Nmap | 服务识别 | 确认本地靶场开放端口、Web 服务和 MySQL 服务 |
| WhatWeb | Web 指纹识别 | 辅助识别 Apache、PHP、DVWA、Pikachu 等信息 |
| dirsearch | 目录枚举 | 发现 `login.php`、`setup.php`、`README.md`、`.dockerignore` 等路径 |
| SQLmap | SQL 注入辅助验证 | 对已手工确认的 SQL 注入点进行复核 |
| Nuclei | 自动化模板扫描 | 识别默认口令、Dockerfile 暴露等模板化风险 |

## 注意事项

本目录中的结果来自本地学习环境，不代表真实生产系统风险。真实安全评估中应严格遵守授权范围，不进行未授权扫描、敏感数据读取或破坏性测试。
