# Web Security Lab Notes 项目展示说明

## 项目简介

本项目是一个基于 DVWA、Pikachu 等本地授权靶场环境完成的 Web 安全漏洞复现与安全评估实践项目。

项目围绕常见 Web 漏洞展开，完成了 SQL 注入、XSS、文件上传、命令执行、目录遍历、弱口令、越权、SSRF、CSRF、XXE、PHP 反序列化等 11 类漏洞的复现、抓包分析、风险说明、修复建议和日志检测思路整理。

项目重点不是简单堆漏洞 payload，而是按照安全服务交付思路，将每个漏洞整理为完整报告，并补充安全运营视角，包括日志特征、告警建议、误报控制和基础日志风险分析脚本。

## 项目目标

* 搭建本地 Web 安全测试环境；

* 熟悉常见 Web 漏洞的成因、验证方式和修复思路；

* 使用 Burp Suite 进行请求抓取和参数分析；

* 按照安全评估报告格式整理漏洞证据；

* 将漏洞复现行为转化为日志检测规则和安全运营分析思路；

* 形成可用于 GitHub 展示和简历说明的安全学习项目。

## 项目亮点

### 1. 证据链完整

每个漏洞均包含：

* 漏洞页面截图；

* 正常请求结果；

* 漏洞触发结果；

* Burp Suite 抓包截图；

* 风险影响说明；

* 修复建议；

* 复测或安全对比说明。

### 2. 不只复现漏洞，也关注修复

项目中整理了 `notes/remediation-cheatsheet.md`，对常见 Web 漏洞的根因、修复建议和面试表达进行了总结。

这使项目不仅能体现漏洞验证能力，也能体现安全整改和开发安全意识。

### 3. 补充安全运营视角

项目中整理了 `notes/log-detection-cheatsheet.md`，将漏洞复现中的攻击请求特征转化为日志检测思路。

覆盖内容包括：

* 可疑请求特征；

* 日志字段分析；

* 告警建议；

* 误报控制；

* 攻击链关联分析。

### 4. 增加可运行日志分析脚本

项目补充了：

```text

tools/access-log-risk-summary.py

```

该脚本可以读取 Web access.log，并基于常见攻击特征生成 Markdown 风险摘要。

示例：

```powershell

python tools\\access-log-risk-summary.py sample-logs\\access-demo.log -o summary\\log-risk-summary.md

```

该部分体现了从漏洞复现到日志分析、告警规则、安全运营研判的能力延伸。

## 安全声明

本项目所有测试均在本地授权靶场环境中完成，仅用于安全学习、漏洞原理理解和防护能力提升。

项目不针对真实公网系统，不包含未授权测试，不包含破坏性攻击行为。
