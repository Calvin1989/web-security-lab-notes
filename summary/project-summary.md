# Web 常见漏洞复现与修复实践：项目总结



## 项目背景



本项目基于本地授权靶场环境，对常见 Web 安全漏洞进行复现、分析和修复建议整理。项目覆盖 SQL 注入、XSS、文件上传、命令执行、目录遍历、弱口令、水平越权、SSRF 等常见 Web 漏洞类型。



所有测试均在 DVWA、Pikachu 等本地靶场中完成，仅用于安全学习和报告编写练习，不涉及真实业务系统或未授权目标测试。



## 项目环境



- 操作系统：Windows

- Web 环境：小皮面板 / PHP / MySQL

- 靶场环境：DVWA、Pikachu

- 辅助工具：Chrome、Burp Suite、Git、Markdown

- 测试方式：本地授权靶场测试

## 项目收获



通过本项目，完成了以下实践内容：



1. 熟悉 DVWA、Pikachu 等本地靶场的部署与使用；

2. 掌握 Burp Suite 抓包、请求分析、参数修改和 Repeater 手工测试；

6. 初步建立安全服务报告交付意识。



## 漏洞理解总结



### SQL 注入



SQL 注入的核心问题是服务端将用户输入直接拼接进 SQL 语句，导致用户输入改变了原本查询逻辑。修复重点是参数化查询、输入类型校验、最小权限和错误信息隐藏。



### XSS



XSS 的核心问题是用户输入被输出到页面中时没有进行安全编码，导致浏览器将输入当作脚本执行。修复重点是输出编码、输入校验、CSP 和 HttpOnly Cookie。



### 文件上传



文件上传漏洞的核心问题是上传文件类型和执行权限控制不严，导致非预期文件被上传并可能被执行。修复重点是白名单、内容校验、重命名、上传目录禁止执行脚本。



### 命令执行



命令执行漏洞的核心问题是服务端将用户输入拼接到系统命令中执行，导致额外命令被执行。修复重点是避免调用 Shell、使用安全 API、白名单校验和低权限运行。



### 目录遍历



目录遍历的核心问题是服务端根据用户传入路径读取文件，但没有限制路径范围。修复重点是文件 ID 映射、路径规范化、读取目录限制和最小权限。



### 弱口令 / 暴力破解



弱口令和暴力破解的核心问题是密码过于简单，且系统允许反复尝试。修复重点是强密码策略、失败次数限制、验证码、账号锁定、多因素认证和日志告警。



### 越权漏洞



越权漏洞的核心问题是服务端没有基于当前登录用户身份进行资源级权限校验。修复重点是服务端鉴权、资源归属校验和异常访问日志。



### SSRF



SSRF 的核心问题是用户可以控制服务器要请求的 URL。修复重点是 URL 白名单、协议限制、内网地址拦截、DNS 解析校验、重定向校验和请求日志监控。
