# 简历项目经历：Web 常见漏洞复现与安全评估实践

## 项目名称

Web 常见漏洞复现与安全评估实践

## 项目描述

基于 DVWA、Pikachu 等本地授权靶场，完成 SQL 注入、XSS、文件上传、命令执行、目录遍历、弱口令、水平越权、SSRF、CSRF、XXE、PHP 反序列化等 11 类 Web 常见漏洞复现。使用 Burp Suite 进行请求抓取和手工验证，结合 Nmap、dirsearch、SQLmap、Nuclei 完成本地服务识别、目录枚举、SQL 注入辅助验证和自动化扫描结果复核，整理漏洞原理、风险影响、修复建议、复测结论和模拟安全评估报告。补充 Web 攻击日志表现与告警建议，并使用 Python 编写 access log 风险摘要脚本，将漏洞复现与安全运营研判关联起来。



## 项目职责

- 搭建 Windows + 小皮面板 + DVWA + Pikachu 本地授权靶场，完成 11 类 Web 常见漏洞复现与报告整理；

- 使用 Burp Suite 分析 HTTP 请求参数、Cookie、请求体和响应结果，完成手工漏洞验证；

- 使用 Nmap、dirsearch、SQLmap、Nuclei 进行资产识别、目录枚举、辅助验证和扫描结果复核；

- 编写 access log 风险摘要脚本，总结 SQL 注入、XSS、暴力破解、目录遍历等攻击行为的日志特征和告警建议。技术栈

DVWA、Pikachu、Burp Suite、PHP、MySQL、HTTP、Markdown、Python、正则表达式、Web Access Log 分析
