\# 简历项目经历：Web 常见漏洞复现与安全评估实践



\## 项目名称



Web 常见漏洞复现与安全评估实践



\## 项目描述



基于 DVWA、Pikachu 等本地授权靶场环境，复现 SQL 注入、XSS、文件上传、命令执行、目录遍历、弱口令、水平越权、SSRF 等常见 Web 漏洞，使用 Burp Suite 进行请求抓取、参数分析和手工验证，整理漏洞原理、复现步骤、风险影响、修复建议和复测结论，形成标准化 Web 漏洞复现报告合集。



\## 项目职责



\- 搭建 Windows + 小皮面板 + DVWA + Pikachu 本地 Web 安全测试环境；

\- 使用 Burp Suite 抓取和分析 HTTP 请求，定位 URL 参数、Cookie、请求体等关键测试点；

\- 复现并分析 8 类常见 Web 漏洞，包括 SQL 注入、XSS、文件上传、命令执行、目录遍历、弱口令、水平越权和 SSRF；

\- 按照安全服务报告格式整理漏洞概述、漏洞原理、复现环境、复现步骤、截图证据、风险影响、修复建议和复测结论；

\- 总结常见漏洞修复方案，包括参数化查询、输出编码、上传白名单、权限校验、路径规范化、登录防护和 SSRF 白名单等。



\## 技术栈



DVWA、Pikachu、Burp Suite、PHP、MySQL、HTTP、Markdown、Git
