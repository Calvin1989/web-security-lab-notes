# Screenshots

本目录用于存放漏洞验证过程中的关键截图证据。当前阶段每个漏洞保留 2-3 张即可，不需要堆叠大量截图。

建议优先保留以下截图：

```text
sql_injection_request
sqlmap_validation_result
file_upload_burp_request
file_upload_response
idor_userid_replace
idor_response_compare
```

截图内容重点：

- Burp 请求包
- 响应差异
- 工具辅助验证结果
- 修复或复测结论

命名建议保持清晰、稳定，方便在报告中引用和面试时讲解。
